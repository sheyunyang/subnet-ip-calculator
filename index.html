🧰 功能工具

🕸️ 子网计算器

根据 IP 与掩码计算网络地址、广播地址、可用主机范围与数量。

📍 IP 信息分析

校验 IP 合法性，判断公网/私网/保留地址并显示二进制与地理位置类型。

✔️ CIDR 包含检查

判断某 IP 是否属于指定 CIDR 网段，用于白名单/访问控制规则核对。
